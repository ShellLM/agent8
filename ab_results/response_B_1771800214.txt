

```xml
<(refined_prompt>
  <objective>
    Consolidate the git repository branches to simplify the project's branch structure.
  </objective>
  
  <current_state>
    The git repository has a messy, disorganized branch structure that needs to be cleaned up.
  </current_state>
  
  <requirements>
    <requirement>
      Analyze the current git branch structure to understand all existing branches.
    </requirement>
    <requirement>
      Review the git history to understand the purpose and content of each branch.
    </requirement>
    <requirement>
      Identify which branches contain stable, production-ready code to be merged into the master branch.
    </requirement>
    <requirement>
      Identify which branches contain experimental, in-progress, or feature work to be merged into the experimental branch.
    </requirement>
    <requirement>
      Perform a clean merge of relevant branches into the master branch, resolving any conflicts appropriately.
    </requirement>
    <requirement>
      Perform a clean merge of relevant branches into the experimental branch, resolving any conflicts appropriately.
    </requirement>
  </requirements>
  
  <constraints>
    <constraint>
      Final branch structure must contain exactly two branches: master and experimental.
    </constraint>
    <constraint>
      Preserve all commit history during the consolidation process.
    </constraint>
  </constraints>
  
  <deliverables>
    <deliverable>
      A clean master branch containing all stable, production-ready code.
    </deliverable>
    <deliverable>
      An experimental branch containing all experimental or in-progress work.
    </deliverable>
    <deliverable>
      A summary report documenting which branches were merged and the rationale for the organization.
    </deliverable>
  </deliverables>
</refined_prompt>
```
